# Fallout: Wastelands

Download the installer from the [latest Release](https://github.com/CricTheBaby/FalloutWastelands/releases/latest).

News, update notes and help: [Discord](https://discord.gg/rpSwBw9Rt4)

## Mods used

Optional, and never hosted by us: the launcher's MODS page downloads each from its author's Nexus Mods page with your own account, into the Wastelands mods folder. Your Fallout 3 and New Vegas installs are never modified.
[Enhanced Movement](https://www.nexusmods.com/newvegas/mods/85459) · [Enhanced Animations](https://www.nexusmods.com/newvegas/mods/95967) · [New Vegas True Scopes](https://www.nexusmods.com/newvegas/mods/74824)
